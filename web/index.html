How this estimate is calculated

How agents work Coordinator assigns checks → Sensor Quality reviews readings → Event Diagnosis compares sensors and records → Coordinator drafts findings → Grounding Reviewer checks the wording → Accepted report → Report-to-map Mapper → Map updates. The mapper is an LLM presentation step, triggered by the backend after acceptance, outside the coordinator workflow. It extracts quoted findings, not a new diagnosis.

New pressure anomalies start investigations automatically. Missing values alone do not start agents.

Execution details

Both modes share the same sensor evidence and detector warnings. Map interpretation and inspection overlays appear only for a reviewed agent report matching the displayed window. The report-to-map mapper copies inspection intervals explicitly stated in the accepted incident report; it does not calculate an exact leak coordinate. Sensor timestamps use simulated source UTC; agent timestamps use real processing time. No automatic actuation or correctness guarantee.
