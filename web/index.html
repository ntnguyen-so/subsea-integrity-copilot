Agent conclusion · separate from the numerical alarm

Processing timestamps and limitations

Both modes share the same sensor evidence and detector warnings. Map interpretation and inspection overlays appear only for a reviewed agent report matching the displayed window. Numerical tools constrain the admissible interval; it is not an exact leak coordinate. Sensor timestamps use simulated source UTC; agent timestamps use real processing time. No automatic actuation or correctness guarantee.
